# zip-page changelog

What changed in each version, newest first, one plain line each. The full technical log, with sizes and test browsers, is kept by the maintainers.

## 1.0.0 · 2026-10-16
- Smaller download: a minified build is 3.6 KB (2.0 KB gzipped), about 33% less. The readable file is still there.

## 1.0.0 · 2026-10-12
- First release: shrinks one HTML file into a page that unzips itself when opened, with no server needed. The README's example goes from 22,219 to 15,774 bytes (about 29% smaller).
